# Credit Card Validator

Виджет для проверки валидности номеров кредитных карт с определением платежной системы.

## Возможности

- Проверка номера карты по алгоритму Луна (Luhn algorithm)
- Определение платежной системы (Visa, Mastercard, American Express, Discover, JCB, Diners Club, МИР)
- Автоматическое форматирование номера карты (XXXX XXXX XXXX XXXX)
- Визуальное отображение результата проверки
- Адаптивный дизайн

## Установка

```bash
git clone https://github.com/yourusername/credit-card-validator.git
cd credit-card-validator
npm install
```
## Тестирование
- Проект включает три уровня тестов:

- Модульные тесты - тестирование функций валидации и определения платежных систем

- DOM тесты - тестирование взаимодействия с DOM с использованием JSDOM

- Интеграционные тесты - тестирование полного пользовательского сценария с Puppeteer

## Запуск всех тестов
```bash
npm test
npm run test:puppeteer
```
## Алгоритм Луна (Luhn Algorithm)
Алгоритм проверки контрольной суммы номера карты:

Удалить контрольную цифру (последнюю)

Начиная с первой цифры справа, удвоить каждую вторую цифру

Если результат удвоения больше 9, вычесть 9

Сложить все цифры

Контрольная цифра = (10 - (сумма mod 10)) mod 10

Сравнить с оригинальной контрольной цифрой

|-------------------|---------------|

| American Express | 34, 37 |

## CI/CD
Проект настроен для автоматического тестирования в GitHub Actions. При каждом пуше в main или создании pull request запускаются:

- Модульные тесты с проверкой покрытия
- Puppeteer тесты
- Загрузка отчетов о покрытии в Codecov
